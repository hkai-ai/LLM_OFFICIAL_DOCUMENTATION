# 火山方舟模型价格

本文所有价格以**人民币（元）**计价。文本类计价单位为**元 / 百万 token**（缓存存储为**元 / 百万 token / 小时**），图片为**元 / 张**，视频为**元 / 百万 token**，3D 为**元 / 次**，插件为**元 / 千次**。具体可购规格与费用以实际下单为准；价格随官方调整，请以[官方定价页](https://www.volcengine.com/docs/82379/1544106)与[价格计算器](https://www.volcengine.com/docs/82379/1099320)为准。

火山方舟大语言模型多数采用**分段计费**：按单次请求的**输入长度区间**（单位 k token，如 `[0, 32]` 指 0–32k）、部分模型还按**输出长度区间**采用不同单价。

```

     + 缓存存储单价 × 缓存存储token × 时长
```

## 视频生成模型

仅对成功生成的视频计费（审核失败等不计费）。按 token 单价 × token 用量计费，单位：元 / 百万 token。

```
token 用量 ≈ (输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 输出帧率 / 1024
```

| 模型 | 在线推理（元/百万token） | 离线推理（元/百万token） |
| --- | --- | --- |
| `doubao-seedance-2.0`（按分辨率/是否含视频输入区分） | 480p/720p 不含视频 46.00、含视频 28.00；1080p 不含视频 51.00、含视频 31.00 | 暂不支持 |
