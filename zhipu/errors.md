# 智谱 BigModel · 错误码

## 响应结构

业务错误返回 JSON：

```json
{
  "error": {
    "code": "1211",
    "message": "模型不存在"
  }
}
```

部分错误同时映射到 HTTP 状态码，详见下表。

## HTTP 状态码层

| HTTP | 含义 | 典型触发 |
| --- | --- | --- |
| `200` | 成功 | — |
| `400` | 参数错误 / 文件内容异常 | 接口参数不正确；JSONL 文件格式不符 |
| `401` | 鉴权失败或 Token 超时 | API 密钥无效 |
| `404` | 资源不存在 | 微调任务不存在 / 微调功能未开放 |
| `429` | 限流或额度异常 | 并发超额；上传频率过快；账户余额已用完；账户 / 终端用户异常 |
| `434` | 暂无 API 权限 | 内测阶段未开放 |
| `435` | 文件大小超过 100MB | 文件过大 |
| `500` | 服务端异常 | 基础服务暂时异常 |

## 业务错误码

### 鉴权与账户（10xx）

| code | message | 触发 |
| --- | --- | --- |
| `500` | 内部错误 | 基础服务异常 |
| `1000` | 身份验证失败 | 认证流程错误 |
| `1001` | Header 中未收到 Authentication 参数 | 缺少认证头 |
| `1002` | Authorization Token 非法 | 令牌格式错误 |
| `1003` | Authentication Token 已过期 | 令牌失效 |
| `1004` | 通过 Token 验证失败 | 令牌校验不通过 |
| `1100` | 账户读写 | 账户访问异常 |
| `1110` | 账户处于非活动状态 | 账户未激活 |
| `1111` | 账户不存在 | 账户无效 |
| `1112` | 账户已被锁定 | 联系客服解锁 |
| `1113` | 账户已欠费 | 充值 |
| `1120` | 无法成功访问账户 | 临时访问异常 |
| `1121` | 账户存违规行为 | 账户被锁定 |

### API 调用（12xx）

| code | message | 触发 |
| --- | --- | --- |
| `1200` | API 调用错误 | 通用调用异常 |
| `1210` | API 调用参数有误 | 参数不符合文档 |
| `1211` | 模型不存在 | 模型代码错误 |
| `1212` | 当前模型不支持该调用方式 | 方法不兼容（如对非视觉模型传 `image_url`） |
| `1213` | 未正常接收到参数 | 参数缺失 |
| `1214` | 参数非法 | 参数值无效 |
| `1215` | 参数不能同时设置 | 参数冲突（如同时设 `temperature` 与 `do_sample=false`） |
| `1220` | 无权访问 API | 权限不足 |
| `1221` | API 已下线 | 功能已废弃 |
| `1222` | API 不存在 | 路径无效 |
| `1230` | API 调用流程出错 | 处理流程异常 |
| `1231` | 已有相同请求 ID | `request_id` 重复 |
| `1234` | 网络错误 | 连接异常 |
| `1261` | Prompt 超长 | 超过上下文窗口 |

### 内容与限流（13xx）

| code | message | 触发 |
| --- | --- | --- |
| `1301` | 内容包含不安全内容 | 安全审核未通过；同时 `choices[].finish_reason: "sensitive"` |
| `1302` | 并发数过高 | 并发限流触发 |
| `1303` | 频率过高 | 频率限流触发 |
| `1304` | 已达今日调用次数限额 | 日限超额 |
| `1305` | 触发流量限制 | 流量限制生效 |
| `1308` | 已达使用上限 | 用量超限 |
| `1309` | GLM Coding Plan 套餐已到期 | 订阅过期 |
| `1310` | 已达周 / 月使用上限 | 周期性限额超额 |
| `1311` | 订阅套餐未开放模型权限 | 模型权限缺失 |
| `1312` | 模型访问量过大 | 模型过载 |
| `1313` | 使用模式不符合公平策略 | 请求频率被限制 |

### 工具 API（17xx）

| code | message | 触发 |
| --- | --- | --- |
| `1701` | 并发限制 | Web Search 并发超额 |
| `1702` | 搜索引擎服务不可用 | 上游异常 |
| `1703` | 无有效数据返回 | 搜索无结果 |

## `finish_reason` 异常值

`choices[].finish_reason` 在非正常结束时可取：

- `sensitive` — 内容审核触发（同时业务码 `1301`）
- `network_error` — 工具调用网络错误
- `model_context_window_exceeded` — 上下文超限（同时业务码 `1261`）

## 排查清单

1. **`401` / `1004`**：检查 `Authorization: Bearer <KEY>`，确认 key 未过期 / 未被禁用。
2. **`1211` / `1220`**：核对模型 ID 拼写与账户是否有该模型权限（部分模型需开通申请）。
3. **`1301` / `finish_reason: sensitive`**：调整 prompt；同时检查 `content_filter` 字段定位敏感角色（`assistant` / `user` / `history`）。
4. **`1302` / `1303`**：使用指数退避；详见 https://docs.bigmodel.cn/cn/api/rate-limit。
5. **`1304` / `1308` / `1310`**：进入下一计费周期或升级套餐。
6. **`1231`**：本端去重 `request_id`，或不传让服务端自动生成。
